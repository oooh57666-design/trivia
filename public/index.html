Trivia Game

Create or join a live trivia room. Host controls the game and players join from their devices. Everything runs in real-time using Firebase Firestore.

Create a new game (Host)

After creating, you'll be taken to the host console.

Join an existing game (Player)

Ask the host for the game id, or join a public room.
Note: This app will write/read game state to Firestore under games/{'{gameId}'}. Make sure your Firebase rules allow that path (we covered the simple rule earlier).
